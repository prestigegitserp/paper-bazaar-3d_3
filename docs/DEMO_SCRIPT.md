# سناریوی ارائهٔ سه‌دقیقه‌ای

1. **۳۰ ثانیه — مسئله:** خرید کاغذ عمده بین قیمت‌های با واحد متفاوت، منابع متعدد و تماس‌های پراکنده گم می‌شود. صفحهٔ اول و دسته‌های کالا را نشان دهید.
2. **۴۵ ثانیه — کشف:** «کاغذ» را جستجو کنید؛ فروشنده را فیلتر کنید؛ دو کالا را برای مقایسه انتخاب کنید. تفاوت واحد و تاریخ مشاهده را توضیح دهید.
3. **۳۰ ثانیه — تجربه:** استودیو را باز کنید، مدل را بچرخانید و رنگ متریال را عوض کنید. تصریح کنید که مدل، نمای مفهومی است.
4. **۴۵ ثانیه — اقدام:** دو کالا را به استعلام بیفزایید، تعداد و شهر تحویل را وارد کنید و پیش‌نویس را دانلود کنید. ارسال واقعی در این دمو انجام نمی‌شود.
5. **۳۰ ثانیه — مسیر توسعه:** اتصال فروشندگان و موجودی معتبر، درخواست قیمت سمت سرور، تحلیل قیف خرید و پایلوت با مشتریان واقعی مراحل بعدی‌اند.

از معرفی اعداد کاتالوگ به‌عنوان مشتری فعال، فروش، رشد یا تأمین‌کنندهٔ طرف قرارداد خودداری کنید. این اعداد فقط محتوای موجود در دمو را شمارش می‌کنند.
